01 / 07
The problem

Space missions are
a balancing act.

A more powerful instrument can require more energy, increase launch mass and consume a larger budget. Students rarely get to test all these decisions together.

How can we make engineering trade-offs tangible?

02 / 07
Our solution

A mission lab
you can play.

Choose a science goalBuild a spacecraftSimulateLearn & iterate

Players design Earth-observation missions for coastal mapping, wildfire heat tracking or broad surface surveys.

Runs in a browser, without an account or API key.

04 / 07
Demonstration

Failure becomes feedback.

FIRST DESIGN

Precision imager + compact array + basic radio.

Energy and data-return checks fail.

REFINED DESIGN

Extended array + endurance battery + high-rate radio + dedicated launch.

All six modeled constraints pass.

The mapping example is reproducible using “Load a viable example.” Outcomes are deterministic educational checks, not flight predictions.

05 / 07
Science & NASA resources

Grounded in systems thinking.

  • Mission lifecycle and systems trade-offs: NASA’s Design and Develop Science Missions, via the challenge resource summary.
  • Objective-to-instrument decisions: NASA’s Build It Yourself telescope game, via the challenge resource summary.
  • Circular-orbit period, simplified eclipse geometry, energy balance and data-return constraints.

All hardware values are illustrative. No NASA hardware dataset is imported. Model, sources, limitations and AI assistance: SOURCES.md.
